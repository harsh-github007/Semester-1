# Retained study-notebook system

Mode: Read for lessons and practice; Operate for the desk, course shelf and tracking.

Preserve the original navy/blue notebook identity and semantic diagram colors. The new layer uses quiet surfaces and a single-column reading sequence so an unfamiliar learner sees the everyday explanation before the math. Existing lesson diagrams remain geometric instructional assets, not decoration.

Tokens: `--paper #f5f7fb`, `--sheet #ffffff`, `--ink #16223a`, `--mut #5a6880`, `--blue #2457d6`, `--green #1d8656`, `--hl #ffe680`, `--line #cfd8e6`; existing dark tokens remain in base.css. Local system font fallbacks keep the app functional without font downloads. Headings 24–48px, body 17px, small/supporting text 13–15px. Reading text is bounded near 70 characters. Focus is a visible 3px blue outline.

Use subject rows for navigation, expandable detail for optional vocabulary and solutions, and one clear primary action per activity. Mobile collapses the sidebar to a lesson selector. Controls target at least 44px except small sketch-step controls, which use expanded hit areas. Reduced motion disables animations. Themes follow system preference unless explicitly selected.

The user asked for beginner comprehension and course-aligned practice, not a replacement brand. No new marketing claims, decorative imagery or external dependencies were introduced.
